# m2-w2-d2-exercise

Module 2, Week 2, Day 2 in-class exercise/demo (GAP Week 6 Day 2): Bootstrap 4 containers, grid system, navs, navbar and utilities.

## Note on the starter files

I was not able to get the `wk2-day2-exercise.zip` starter files from GAP.
Because of that, I recreated each demo page from the exercise slides and then applied the Bootstrap classes the slides ask for.
The page content may differ slightly from the original starter files, but each file has the classes from the exercise.
